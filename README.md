## 🌟 Overview

**Akram Marref** is an Art Director and Senior Graphic Designer with over 5 years of industry experience crafting compelling brand identities, editorial design, premium packaging, websites, and intuitive digital interfaces.

This portfolio is built on a high-speed, autonomous, and self-hosted Vite architecture delivering instant rendering, fluid kinetic typography, and seamless micro-interactions with zero platform lock-in.

---

## ⚡ Key Highlights

- **100% Autonomous & Self-Hosted**: Free from external platform locks, subscription walls, or third-party watermark badges.
- **Pixel-Perfect Fidelity**: Preserves all typography tokens, dark aesthetic grids, and high-fidelity project showcases.
- **Kinetic Micro-Interactions**: Features dual-span rolling hover typography, smooth reveal animations, and inertia-based scrolling.
- **High-Performance Asset Pipeline**: Optimized media and local web font formats ensuring instant First Contentful Paint (FCP).
- **Clean & Unbranded**: All watermarks, third-party analytics trackers, and template badges have been removed.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/arabiabdou453-cpu/akram-marref-site.git
   cd akram-marref-site
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
